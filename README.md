# Moda Click — Colección OPHIDEA

Sitio web oficial de la boutique de alta costura contemporánea **Moda Click**, centrado en la **Colección OPHIDEA**. Diseñado bajo estándares de lujo, estética minimalista y máxima velocidad de carga.

## 🐍 Características Principales
- **Diseño de Identidad:** Logo vectorial SVG propio de cobra minimalista con degradado dorado cromado.
- **Catálogo de Lujo:** 20 productos de alta moda sin imágenes de relleno (todas enlazadas a Unsplash HD).
- **Lógica de Estado Local:** Carrito de compras y sistema de favoritos en la memoria del navegador (`localStorage`).
- **Despliegue Inmediato:** Preparado para hosting estático en Netlify o GitHub Pages.
- **Optimizaciones SEO:** Estructura semántica, metaetiquetas de visibilidad y protocolo Open Graph preconfigurados.

## 🛠️ Despliegue en Netlify
1. Descarga o clona estos 4 archivos en la raíz de tu proyecto.
2. Sube la carpeta a tu repositorio de GitHub.
3. Importa el repositorio desde Netlify y haz clic en **Deploy Site**.
